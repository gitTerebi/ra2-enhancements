RA2 HWCursor + WASD
===================
https://github.com/gitTerebi/ra2-enhancements

Two features, one DLL each. Copy only the ones you want into your game
folder (the one with gamemd.exe / game.exe in it).

  HWCursor.dll     hardware mouse cursor. RA2 blits its cursor into the
                   frame like any other sprite, so the pointer only moves
                   when the game draws. This makes it a real Windows
                   cursor, which moves at your mouse's poll rate instead.
                   Colours and hotspots come from the game's own art.

  WasdScroll.dll   smooth WASD map scrolling, on top of the arrow keys and
                   edge scroll you already have. Ctrl and Alt are ignored
                   so hotkeys still work.


Any install, vanilla or Syringe
-------------------------------
dsound.dll is the loader and does nothing else, so it is always needed.

  Cursor          dsound.dll + HWCursor.dll
  WASD            dsound.dll + WasdScroll.dll
  Both            dsound.dll + HWCursor.dll + WasdScroll.dll

The game imports DirectSound statically, so Windows loads our dsound.dll
from the exe's folder whatever the working directory is. It forwards all 12
exports to the real C:\Windows\SysWOW64\dsound.dll, so audio is untouched,
then loads whichever feature DLLs it finds beside it. No launcher, no
renaming, nothing else.

The same files work on Mental Omega, C&C Reloaded and other Syringe mods.
No .inj files or -i= entries are needed. Delete any old HWCursor.dll.inj
and WasdScroll.dll.inj.


Uninstall
---------
Delete the file for the feature you do not want. The DLLs are independent,
so removing one leaves the other working.


Also worth having
-----------------
RA2Enhancements.dll adds engine fixes and game speed keys. dsound.dll
loads it the same way. It is in the same
repo, in the ra2enhancements folder, and in its own release zip.

RA2Video.exe is the resolution and window picker for cnc-ddraw. It is in
the same repo, in the ra2video folder.

cnc-ddraw-ra2 is a renderer fork whose fixchilds=5 keeps the RA2 menus
clickable while the game is upscaled:
https://github.com/gitTerebi/cnc-ddraw-ra2


Files
-----
dsound.dll           DirectSound proxy and loader, always needed
HWCursor.dll         hardware cursor
WasdScroll.dll       WASD scroll, optional
