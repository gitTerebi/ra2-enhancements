Hardware mouse cursor for Red Alert 2 and Yuri's Revenge

Red Alert 2 paints its mouse cursor into the frame, so the pointer only moves when the game draws. This add-on gives you a real Windows cursor that moves at your mouse poll rate, whatever the game is doing. It also adds WASD map scrolling, game speed keys and quick save.

It works on Red Alert 2, Yuri's Revenge and Mental Omega. There is no launcher and no patched game exe. You copy a few DLL files into your game folder, and you delete them to uninstall.

Why the RA2 cursor feels laggy

This is the question most people arrive with, so here is the short answer.

Red Alert 2 blits its cursor into the frame like any other sprite. The pointer therefore moves once per drawn frame. At the stock 30 frames per second your 1000 Hz mouse still only moves the pointer 30 times a second, and every dropped frame freezes it in place. The effect gets worse at high resolutions, where the game draws fewer frames.

A hardware cursor is drawn by Windows rather than by the game, so it keeps moving even while the game is busy. That is what HWCursor.dll switches on. The pointer art, colours and hotspots still come from the game's own cursor files, so it looks exactly like Red Alert 2.

Stock game

30 updates/sec

The cursor is a sprite in the frame. It moves only when the game draws, and it stops dead during a stutter.

With HWCursor

Your mouse poll rate

Windows draws the cursor. It keeps moving at 125, 500 or 1000 Hz no matter what the game does.

What is in the download

Three folders, each independent. Take only the pieces you want, because every DLL works on its own and deleting one leaves the rest running.

Hardware cursor

A real Windows cursor built from the game's own cursor art, so the pointer never waits for a frame. Ships as HWCursor.dll.

WASD map scrolling

Smooth sub-pixel map scrolling on W, A, S and D, on top of the arrow keys and edge scroll you already have. Ctrl and Alt are ignored so your hotkeys still work. It is a separate DLL, so leave it out if you do not want it.

Game speed keys

[ and ] step the game speed through seven steps from the stock 30 fps up to 60 fps. The chosen step is written to the game ini and read back on the next launch.

Quick save and quick load

F5 saves and F9 loads, in campaign and in skirmish. Two slots rotate, so a damaged save still leaves you the one before it. Both appear in the normal Load menu.

One voice on select all

Select-all-of-type and select-all-combatants used to make every unit shout its select line at once, which clipped the mix. Now one unit answers, the same as a band-box selection.

Shift queue five

Shift-click a sidebar cameo to queue five of that unit, and shift right-click to remove five. This stays off in Mental Omega, which already does it.

Healers escort the group

The stock game sends a Repair IFV straight at the enemy when you attack. Now every healer in the selection guards an armed unit from the same selection instead, spread across the width of your army.

Spawner units fight on Guard Area

Aircraft Carriers, Dreadnoughts and V3 Launchers pick their own targets on Guard Area, at full weapon range and across movement zones, so a ship can finally hit a land target. Campaign and skirmish only.

Resolution tool

RA2Video.exe writes the render resolution to the game inis and the window size, position and shader chain to ddraw.ini, for anyone running cnc-ddraw.

Install

Download the zip and copy files into your game folder, the one holding gamemd.exe or game.exe. The same files work on unmodded Red Alert 2 and Yuri's Revenge and on Syringe mods such as Mental Omega and C&C Reloaded.

Any install, with or without Syringe
What you wantFiles to copy
Hardware cursordsound.dll + HWCursor.dll
WASD scrollingdsound.dll + WasdScroll.dll
Speed keys, quick save and the engine fixesdsound.dll + RA2Enhancements.dll
Everythingdsound.dll and all three feature DLLs

dsound.dll is the loader. The game statically imports DirectSound, which means Windows loads this file from the folder holding the game exe, whichever launcher started it. It forwards all twelve DirectSound exports to the real C:\Windows\SysWOW64\dsound.dll, so your audio is untouched. At the start of the game's main function, after Syringe has set up any mod, it loads whichever feature DLLs it finds beside it.

On a Syringe mod you need no .inj files and no -i= entries in the mod's launcher settings. If an older version left HWCursor.dll.inj, WasdScroll.dll.inj, RA2Enhancements.dll.inj or -i= entries for those DLLs, delete them. campaignspeed.log in the game folder lists what loaded. To uninstall anything, delete its files.

Compatibility

  • Tested against Steam Yuri's Revenge 1.001 (gamemd.exe), Red Alert 2 (game.exe), Mental Omega through Syringe 0.7.3.0, and C&C Reloaded 2.7.0 with Ares and Phobos, from both its client and its randomizer.
  • Every DLL checks the exe it lands in and refuses to patch anything it does not recognise, so a build that does not match your game does nothing rather than crashing.
  • Every code write goes through a guard that leaves a feature switched off if another mod already changed that code, so this sits alongside other patches instead of fighting them.
  • Multiplayer is safe for the cursor and the camera. Those change drawing and your own view, not game logic or the network protocol. The two features that do change logic, the spawner Guard Area behaviour and the healer escort, are limited to campaign and skirmish or sent as ordinary network events.
  • cnc-ddraw works fine. If you upscale the game, cnc-ddraw-ra2 is a fork whose fixchilds=5 keeps the Red Alert 2 menus clickable at a scaled resolution.

Questions people ask

Will this get me banned or flagged on CnCNet?

The cursor and the camera changes only affect what your own machine draws. They send nothing and they change no game rule. The features that do touch game logic issue ordinary network events, the same ones the game sends when you click. Nothing here reads memory the game does not already show you.

Does replacing dsound.dll change the sound?

No. That file forwards all twelve DirectSound exports straight to the real dsound.dll in C:\Windows\SysWOW64. It exists because DirectSound is a DLL every copy of the game loads from its own folder, so it works as a loader on any install.

Do I have to patch or replace the game exe?

No. Everything is loaded at runtime. The game exe on disk is never modified, so a Steam or Origin file check has nothing to complain about.

Does it work with Mental Omega?

Yes. Copy the same files as for the unmodded game, dsound.dll plus the feature DLLs you want. No .inj files are needed. Note that Mental Omega needs its own patched build of Syringe, which is a Mental Omega requirement rather than anything to do with this project.

Can I take only the cursor and nothing else?

Yes, and that is the normal case. Each feature is a separate DLL. Copy dsound.dll and HWCursor.dll for the cursor alone, and leave the others out.

Why does the game still feel choppy after I install this?

The cursor moves independently of the frame rate now, but the game itself still draws at its own pace. If the picture is choppy rather than the pointer, look at your renderer and resolution. cnc-ddraw plus a sensible render resolution usually fixes it, and RA2Video.exe in this project sets both.

Is the source available?

Yes, all of it, under the MIT licence. The GitHub repository holds the full C++ source, the build scripts and notes on how each game address was found.
